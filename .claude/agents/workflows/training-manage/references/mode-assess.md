# Mode 1: 품질 평가 (assess) — 상세 절차

## Step 1: 파일 수집

```bash
find 20_Training/{target}/ -name "*.md" -type f
```

## Step 2: 개별 평가 기준

| 기준 | 점수 | 설명 |
|------|------|------|
| 내용 충실도 | 1-5 | 핵심 개념/원칙/사례가 체계적으로 기록되었는가 |
| 실무 가치 | 1-5 | 현재 업무에 참고할 수 있는 인사이트가 있는가 |
| 완성도 | 1-5 | 빈 섹션 없이 완성되었는가 |

## Step 3: 분류 기준

| 평균 | 분류 | 조치 |
|------|------|------|
| 4.0+ | **KEEP** | 구조 표준화만 수행 |
| 2.5-3.9 | **KEEP (보완)** | 표준화 + 빈 섹션 보완 |
| 1.5-2.4 | **MERGE** | 관련 노트와 통합 검토 |
| 1.0-1.4 | **DELETE** | 삭제 권고 |

DELETE 확정 기준 (하나라도 해당하면 점수와 무관하게 삭제 권고 — 확정 기준이 점수 분류보다 우선):
- 본문이 3줄 이하
- 70% 이상이 빈 섹션 (제목만 있고 내용 없음)
- 이미지만 있고 텍스트 설명 없음
- 순수 인덱스/목차 노트 (하위 노트가 별도 존재)
- 재참고 가치 없는 일반 상식 수준 내용

## Step 4: 보고 포맷

```markdown
## 품질 평가 보고서

| 파일명 | 충실도 | 가치 | 완성도 | 평균 | 분류 | 사유 |
|--------|--------|------|--------|------|------|------|
| ... | ... | ... | ... | ... | KEEP | ... |

### 삭제 대상 (N개)
- {파일명} -- {사유}

### 병합 대상 (N개)
- {파일명} → {병합 대상 파일명}

### 기타
- 고아 이미지: {경로}
- 루트 레벨 파일: {경로} → {이동 권고}
```

사용자 확인 후 다음 단계로 진행한다.
