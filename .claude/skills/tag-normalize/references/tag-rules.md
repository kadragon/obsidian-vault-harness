# Tag Rule Reference Tables

Complete mapping tables for `#업무` and `#부서` tag normalization.

---

## `#업무` — Allowed areas

> **Source of truth = `10_Areas/` 폴더명.** 허용되는 `#업무/{area}` 집합은 런타임에
> `10_Areas/`의 하위 폴더 이름에서 그대로 도출된다 (문서 유형 불문). `validate-tags.sh`와
> `validate_tag.py`는 이 목록을 하드코딩하지 않고 매번 `10_Areas/`를 읽어 검증한다.
> 따라서 area를 추가·이름변경하려면 **`10_Areas/` 폴더를 바꾸면 되고**, 이 표는 갱신을
> 잊으면 오래될 수 있으므로 참고용 스냅샷일 뿐이다 (2026-06 기준 17개).

| area | 대표 subarea 예시 |
|------|------------------|
| AI플랫폼 | AI 플랫폼 관련 |
| 강사료퇴직금 | 강사료, 퇴직금 산정·지급 |
| 개발공통 | 권한관리, 설문, 보안정책관리, 로그, 백업, 할일관리, 직무강도조사관리 |
| 과업심의 | 과업 심의 |
| 교수업적 | 교육영역 |
| 교직 | 교육봉사, 적인성, 기초자료 |
| 구전자문서 | 구 전자문서 시스템 |
| 등록 | 등록대상자, 기초자료, 출력물 |
| 수강신청 | 수강신청 시스템 |
| 수업성적 | 성적관리, 출석부관리, 교육과정관리, 강의계획서관리, 강좌관리, 시간표 |
| 시설물이용 | 이용자예약하기, 호실예약, 통계, 시설물관리 |
| 예산관리 | 예산 관련 |
| 전임교원공채 | 서류접수, 출력물, 성적, 지원자, 심사자관리, 공채정보 |
| 졸업 | 졸업사정관리, 논문관리, 기초코드 |
| 코러스 | 행정업무포털, 인사관리 |
| 행정 | 행정 일반 (자료제출, 지출, 근무성적평가 등) |
| 홈페이지 | 콘텐츠, 게시물, 배너, 학과홈페이지, 대학원홈페이지 |

## `#업무` — Conversion examples

| 잘못된 태그 | 올바른 태그 | 이유 |
|------------|-----------|------|
| `#업무/학사/수업성적/강좌관리` | `#업무/수업성적/강좌관리` | `학사/` 금지 접두어 |
| `#업무/공통/홈페이지/게시물` | `#업무/홈페이지/게시물` | `공통/` 금지 접두어 |
| `#업무/공통/시스템/권한관리` | `#업무/개발공통/권한관리` | `공통/시스템/` → `개발공통` |
| `#업무/인트라넷/학생서비스/공결신청` | `#업무/수업성적/출석부관리/공결신청` | 실제 업무 도메인 기준 |
| `#업무/수업성적/성적관리/학점교류(아웃바운드)관리` | `#업무/수업성적/성적관리/학점교류_아웃바운드_관리` | 괄호 → 언더스코어 |

## `#부서` — 직급 분류

| 분류 | 표기 | 대상 |
|------|------|------|
| 팀장급 이상 | 원래 직함 유지 | {업무}팀장, 과장, 원장, 총장, 대학장, 담당관, 실장 |
| 조교 | `조교` | 조교, 계약직조교 |
| 전문직 | 원래 직함 유지 | 기록연구사, 학예연구사, 전문상담원, 입학사정관, 연구원, 교수 |
| 일반 행정직 | `주무관` 통일 | 행정서기(보), 행정주사보, 전산서기보, 전산주사, 사서주사보, 대학회계직(사무원), 한시임기제 |
| 행정주사 (6급) | `팀장` 변환 | 실제 팀 직함이 있으면 `{업무}팀장`, 없으면 `팀장` |

## `#부서` — 부서명 매핑

| 정규 명칭 | 흡수 대상 |
|-----------|-----------|
| `대외협력부` | `대외협력과`, `대외협력본부` |
| `대학원` | `일반대학원`, `교육대학원` |
| `교육정책전문대학원` | 별도 유지 |
| `정보전산원` | `교육정보원` |
| `총무과` | `학총무과`(오타) |
| `입학인재관리과` | `입학학생처` |
| `학과/{학과명}` | `제X대학/{학과명}`, `{학과명}` 직접 사용 |
| `제1대학`~`제4대학` | 단과대학 행정실 직원용 유지 |
| `외부/{기관명}` | 외부 기관 (한국사학진흥재단 등) |
