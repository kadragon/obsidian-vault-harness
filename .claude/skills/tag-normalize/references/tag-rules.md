# Tag Rule Reference Tables

Complete mapping tables for `#업무` and `#부서` tag normalization.

---

## `#업무` — Allowed areas (18개)

| area | 대표 subarea 예시 |
|------|------------------|
| 수업성적 | 성적관리, 출석부관리, 교육과정관리, 강의계획서관리, 강좌관리, 시간표 |
| 홈페이지 | 콘텐츠, 게시물, 배너, 학과홈페이지, 대학원홈페이지 |
| 일반서무 | 자료제출, 지출, 근무성적평가 |
| 개발공통 | 권한관리, 설문, 보안정책관리, 로그, 백업, 할일관리, 직무강도조사관리 |
| 장학 | 근로장학관리, 국가장학, 학자금대출관리, 장학자료업로드, 장학생관리 |
| 전임교원공채 | 서류접수, 출력물, 성적, 지원자, 심사자관리, 공채정보 |
| 시설물이용 | 이용자예약하기, 호실예약, 통계, 시설물관리 |
| 졸업 | 졸업사정관리, 논문관리, 기초코드 |
| 코러스 | 행정업무포털, 인사관리 |
| 등록 | 등록대상자, 기초자료, 출력물 |
| 교육연구학생지도 | 교육활동, 연구활동, 학생지도활동, 학생안전지도, 지표관리 |
| 기타 | 사도교육원, 연가, 교육신청, 학부입시 (**다른 17개 area에 해당하지 않는 경우에만** 사용) |
| 예산관리 | 예산 관련 |
| 교직 | 교육봉사, 적인성, 기초자료 |
| 교수업적 | 교육영역 |
| 수강신청 | 수강신청 시스템 |
| 구전자문서 | 구 전자문서 시스템 |
| 학적 | 학적변동승인, 학적관리 |

| `#업무/공통/홈페이지/게시물` | `#업무/홈페이지/게시물` | `공통/` 금지 접두어 |
| `#업무/공통/시스템/권한관리` | `#업무/개발공통/권한관리` | `공통/시스템/` → `개발공통` |

## `#부서` — 직급 분류

| 분류 | 표기 | 대상 |
|------|------|------|
| 팀장급 이상 | 원래 직함 유지 | {업무}팀장, 과장, 원장, 총장, 대학장, 담당관, 실장 |
| 조교 | `조교` | 조교, 계약직조교 |
| 전문직 | 원래 직함 유지 | 기록연구사, 학예연구사, 전문상담원, 입학사정관, 연구원, 교수 |
| 일반 행정직 | `주무관` 통일 | 행정서기(보), 행정주사보, 전산서기보, 전산주사, 사서주사보, 대학회계직(사무원), 한시임기제 |
| 행정주사 (6급) | `팀장` 변환 | 실제 팀 직함이 있으면 `{업무}팀장`, 없으면 `팀장` |

## `#부서` — 부서명 매핑

| 정규 명칭 | 흡수 대상 |
|-----------|-----------|
| `대외협력부` | `대외협력과`, `대외협력본부` |
| `대학원` | `일반대학원`, `교육대학원` |
| `교육정책전문대학원` | 별도 유지 |
| `정보전산원` | `교육정보원` |
| `총무과` | `학총무과`(오타) |
| `입학인재관리과` | `입학학생처` |
| `학과/{학과명}` | `제X대학/{학과명}`, `{학과명}` 직접 사용 |
| `제1대학`~`제4대학` | 단과대학 행정실 직원용 유지 |
| `외부/{기관명}` | 외부 기관 (한국사학진흥재단 등) |
