# `_round.json` — 회차 설정

`scripts/round_setup.py`가 읽는 회차 설정 파일이다. 회차 폴더 루트(`10_Areas/과업심의/{연월}_제{N}차과업심의/_round.json`)에 둔다. 아래 값은 모두 사람이 정하는 판단 값이다. 스크립트는 이 값을 서식에 옮기기만 한다.

```json
{
  "round": 10,
  "review_start": "2026-10-08",
  "review_end": "2026-10-12",
  "chair": "김승현",
  "members": [
    {"name": "김승현", "org": "정보전산원", "position": "정보전산원장"},
    {"name": "김경미", "org": "충청북도교육청", "position": "과장", "consent": true},
    {"name": "정승원", "org": "교육부", "position": "", "consent": true}
  ],
  "projects": [
    {"id": "2026-035", "title": "수업 데이터 기반 … 구축 용역", "dept": "융합교육연구소", "period": true},
    {"id": "2026-036", "title": "… 콘텐츠 개발·보급 위탁 용역", "dept": "산학협력단", "period": false}
  ]
}
```

| 키 | 들어가는 곳 | 정하는 기준 |
| --- | --- | --- |
| `round` | 개인정보 동의서 `제{N}회` | 회차 |
| `review_start` | 서약서·위원별 결과서·위원별 산정서 날짜 | 개별심의일 |
| `review_end` | 종합 결과서 하단 날짜·종합 산정서 날짜. 심의기간은 `2026년 10월 8일~12일`로 자동 표기 | 종합심의일. 당일 심의면 `review_start`와 같게 둔다 |
| `chair` | 종합 결과서·종합 산정서 위원장란(글자 사이 공백) | 당연직 정보전산원장. 발주부서가 정보전산원이면 제척되어 다른 위원이 맡는다(프로세스 Step 8) |
| `members[]` | 서약서 소속·직위·성명, 위원별 서류 파일명 | 순서는 통합본 생성 순서다. 위원장도 넣는다. 위원장 제외 1~5명만 지원한다 |
| `members[].position` | 서약서 직위 | 모르면 `""`(공란) |
| `members[].consent` | 통합본 첫 장에 개인정보 동의서를 붙임 | 첫 위촉 외부위원만 `true` |
| `projects[].id` | 폴더명·파일명·확정요청번호 | 직전 회차 다음 번호부터 공문 접수순(Step 8) |
| `projects[].title` | 사업명·제목(`{사업명} 과업 확정 심의`) | 심의요청서 사업명 칸. 칸에 상위 사업명이 있으면 공문 과업명 |
| `projects[].dept` | 발주부서 | 심의요청서 발주부서 |
| `projects[].period` | 적정사업기간 산정서(`_3` 위원별·`_5` 종합) 생성 여부와 번호 체계 | SW 개발사업(FP 산정표 제출)이면 `true`. 구매·유지보수·콘텐츠는 `false` |

## 생성 규칙 (코드가 고정)

- 파일명: `{id}_{순번}_{서류명}_{위원}.hwpx`. 산정 대상은 `_1` 서약서 · `_2` 위원별 결과서 · `_3` 위원별 산정서 · `_4` 종합 결과서 · `_5` 종합 산정서이고, 비대상은 `_1`·`_2`·`_3` 종합 결과서다.
- 종합 서명란: 위원 전원 + 위원장. 2열 행 우선으로 위원을 채우고 위원장은 오른쪽 열에 둔다(위원 1명 `위원|위원장`, 4명 `위원|위원 / 위원|위원 / 빈칸|위원장`). 종합 결과서는 위쪽부터, 종합 산정서는 아래쪽에 붙여 배치한다. 위원 이름은 비워 두고 Step 10에서 채운다.
- 비워 두는 칸: 승인 체크, 검토의견, 산정서 검토의견·개월 수. 대필하지 않는다.
- 심의장소는 서식값 `서면심의`를 쓴다.

## 서식 바꾸기

`assets/forms/*.hwpx`는 값 자리를 `{{토큰}}`으로 바꾼 서식이다. 출처와 토큰 목록은 `assets/forms/README.md`에 있다. 서식을 바꾸면 `tests/test_round_setup.py`를 돌리고, 직전 회차 폴더에서 `generate --out {임시폴더}` 결과가 현행 파일과 텍스트로 같은지 확인한다.
