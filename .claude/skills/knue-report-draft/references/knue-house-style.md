# KNUE 보고서 관행

볼트에 있는 한국교원대학교 보고서 57건(2022~2026)을 분석해 정리한 관행이다. 분석일은 2026. 9. 28.이다. prod:report-draft `style-rules.md`의 일반 규칙과 다르면 아래 우선순위로 정한다.

1. 사용자 직접 지시(`docs/harness-log.md` 규칙 근거 표): 번호 대신 `□ > ○ > - > ※`, 현황·문제점에 대안 금지, 기대효과는 상위 목표 관점, kr-style 윤문.
2. 이 문서의 KNUE 관행
3. `style-rules.md`의 일반 출처(대통령비서실 매뉴얼 등)

외부 작성본은 분석에서 뺐다: 수행사 완료보고서, 교육부 사이버안전센터 점검 결과보고서, 개인 제출 서식(동호회 결과보고서, 교육훈련 결과 보고서).

## 1. 작성 주체별 형태

| 주체 | 날짜·부서 줄 | 장 제목 | 2단계 기호 |
|------|--------------|---------|------------|
| 정보전산원 1쪽 보고 | `<정보전산원, 2026. 8. 20.>`. 월만 적는 변형(`2026. 9.`)과 담당자 변형(`<교육정보원 주무관 강동욱 3346, 2025. 4. 29.>`)이 있음 | 없음. `□`가 1단계 | `○` |
| 정보전산원 계획서 | 표지: 제목 → `2025. 6.` → `한국교원대학교 정보전산원` | 1행 표의 `Ⅰ`~`Ⅴ` | `○` |
| 본부 계획(기획평가과·재무과·총무과) | 표지: 제목 → `2026. 1.` → `[기획처 기획평가과]` | 숫자 상자(`1 추진배경`) 또는 `Ⅰ`~`Ⅴ` | `◦` |
| 기관 서식 | `< 정보전산원, 강동욱(정보화지원팀장), ☎3346 >` | 서식 그대로 | 서식 그대로(대부분 `◦`) |

- 부서명은 2026. 7. 이후 문서에서 `정보전산원`을 쓴다. 그 전 문서는 `교육정보원`이다. 새 보고서는 `정보전산원`으로 쓴다.
- `◦`는 본부 서식의 `○`다. 정보전산원이 쓰는 보고서는 `○`를 쓰고, 본부가 배포한 서식을 채울 때는 서식의 `◦`를 유지한다.
- 1쪽 보고형에서 `□` 바로 아래에 `-`를 두는 것은 2026년 문서의 관행이다(추진 계획 보고, 검토 결과 보고 3건). lint R2는 WARN으로 둔다.

## 2. 제목

- 사업명 전체를 제목 첫머리에 홑낫표로 쓴다: `「교수자 인공지능 활용 지원 사업」 추진 계획`, `「교수자 인공지능 활용 지원 사업」 AI 지원방식 검토`.
- 특강·행사 결과는 행사명을 홑낫표로 쓴다: `「ChatGPT 기초 활용법」 특강 결과 보고`.
- 끝말: `계획(안)`, `추진 계획`, `계속 추진 계획`, `검토`, `검토 결과 보고`, `결과 보고`. 파일명에는 `보고`를 붙이기도 하지만 본문 제목에는 붙이지 않은 문서가 많다. `추진계획`처럼 붙여 쓴 제목은 본부 문서에 있다. 정보전산원 문서는 띄어 쓴다.
- 국립대학 육성사업 재원 계획(안)은 파일명에 과제 코드를 붙인다: `(육성 5-3-3) … 사업 계획(안)`.

## 3. 유형별 실제 골격

`style-rules.md` §1의 골격과 다른 유형만 적는다.

| 유형 | 실제 골격 |
|------|-----------|
| 1쪽 계획 | `□ 추진배경` → `□ 현황 및 문제점` → `□ 개선 방안` → `□ 추진 계획` |
| 계속 추진 계획 | `□ {전년}학년도 사업 추진 실적` → `□ 만족도 조사 결과` → `□ {당해}학년도 수요조사 결과` → `□ 예산 소요` |
| 특강·행사 결과 보고 | `□ 추진 배경` → `□ 특강 개요` → `□ 특강 내용` → `□ 참석자 현황` → `□ 만족도 조사 결과` → `□ 향후 개선 방안` → `□ [붙임1] 참석자 명단` |
| 검토 보고(비교형) | `□ 검토 개요` → `□ 방식별 비교`(표) → `□ 적용 방향(안)` |
| 검토 결과 보고(단일안) | `□ 검토 개요` → `□ 검토 결과`(`[장점]`·`[단점]`) → `□ 종합 의견` |
| 사업 결과 보고 | `Ⅰ 사업 개요`(`□ 개요`·`□ 추진 배경 및 필요성`·`□ 사업 목표`) → `Ⅱ 사업추진 내용`(`□ 추진체계`·`□ 주요 추진 내용`·`□ 추진 결과`) → `Ⅲ 향후 추진 계획` → `Ⅳ 부록` |
| 의견 검토결과 | `□ 검토 개요` → `□ 의견별 검토결과`(표: 연번·제출자·의견 요지·검토의견·조치결과) → `□ 후속 조치 필요사항` → `□ 종합 의견` |
| 개선 계획(규정 근거) | `□ 현황` → `□ 문제점` → `□ 관련 법령` → `□ 개선 방법` → `□ 개선 세부 내역` |

- 사업 결과 보고의 추진 경과는 날짜를 앞세운 시간순으로 쓴다: `○ 2024. 5. 10. 구축 납품 기한 변경`. 일정이 바뀌면 `(당초) 2024. 5. 21. → (변경) 2024. 7. 22.`와 사유를 적는다.
- 의견 검토결과의 조치결과 칸은 판정을 먼저 쓴다: `반영(…)`, `조건부 반영(…)`, `부분반영`, `해당없음(…)`. 종합 의견에서 건수를 모은다: `▶ 제출된 10건은 반영 6건, 조건부 반영 1건, 부분반영 1건, 해당없음 2건으로 처리함`.
- 계획서형의 사업 개요는 괄호 라벨 목록으로 쓸 수 있다: `(추진기간) 2025. 3. 1. ~ 2026. 2. 28.(1년)`, `(관련근거) 「…」 제5조`.
- 계획서에는 일정 단계로 `소프트웨어 과업심의`를 넣는다(SW 사업, 4건 중 4건).

## 4. 결론과 요청 사항

- KNUE 보고서에는 `건의 사항`·`결정 필요` 장이 없다(24건 중 0건). 요청 사항은 제목 끝말로 드러난다: `계획(안)`은 결재, `검토 보고`는 방향 결정, `결과 보고`는 인지.
- 결론 위치는 두 곳이다. 계획은 추진 배경 끝의 `⇒ …필요` 한 줄에, 검토는 마지막 `□`(`적용 방향(안)`·`종합 의견`)에 둔다.
- 적용: `style-rules.md` §0 "결론 먼저"는 첫 `□`의 결론 한 줄(`⇒`)로 지키고, 검토 보고는 끝 `□`의 종합 의견도 유지한다. 사용자가 요청하지 않으면 `건의 사항` 장을 새로 만들지 않는다.

## 5. 문장

- 명사형 종결이 기본이다. `○`·`-` 문장의 약 68%가 `~운영`, `~구축`, `~발생 가능`, `~역할 수행`처럼 명사로 끝난다(정보전산원 444줄, 본부 355줄 측정).
- `~함`·`~임`·`~음`은 판단·상태를 적을 때 쓴다(4~8%): `실질적인 지원은 미미함`, `…중요 자산임`.
- `~필요`는 추진 배경·필요성의 결론에 쓴다: `…체계 마련 필요`.
- `~예정`은 확정되지 않은 일정에 쓴다. 표·일정에서는 `<예정>`·`(예정)`을 붙인다.
- 한 `□` 안에서는 종결 방식을 섞지 않는다. `~습니다`는 서식의 서명 문구(`위와 같이 제출합니다.`)에만 쓴다.
- 라벨은 괄호를 기본으로 쓴다: `(도구 선택형)`, `(법적 의무 준수)`. 장단점 비교만 대괄호를 쓴다: `[장점]`, `[단점]`.

## 6. 표기

- 근거 문서: `교육정보원-548(2026. 2. 4.) “제목”`처럼 문서 제목은 겹따옴표로 쓴다. 홑낫표는 법령·사업명·행사명에 쓴다.
- 결재 근거: `「…」 계획 수립<총장결재>(2025. 6. 10.)`.
- 붙임: 본문에서 `[붙임1] 참고` 또는 `(붙임 1 참조)`, 끝에서 `□ [붙임1] 참석자 명단`. 보고서에는 `끝.`을 쓰지 않는다(41건 중 0건, 기안문에만 있음).
- 연도: 대학회계·학사·사업 실적은 `학년도`, 국립대학 육성사업은 `년`, 중기재정운용계획은 `(2025-2029)`를 쓴다.
- 일정의 약식 날짜 `’26. 5.`는 1쪽 요약과 일정 표에 쓴다. 본문 문장은 `2026. 5. 14.`로 쓴다.
- 금액: 본문 `총 123,664,000원(금일억이천삼백육십육만사천원)`, 표 `(단위: 천원)`, 산식 `450천원×4회=1,800천원`. 기관 서식은 서식 단위(`백만원` 등)를 따른다.
- 쌍점은 앞을 붙인다(`사업명: …`). 2022년 이전 문서의 `결재라인 : …`은 따르지 않는다.

## 7. 기관 서식

기관 서식은 제목·장 제목·표 머리·산식·점수 구간을 원문 그대로 둔다. 부서가 채우는 곳은 칸 내용과 `-` 이하뿐이다. lint는 `--allow-numbered`로 돌린다.

| 서식 | 고정 골격 | 채우는 문형 |
|------|-----------|-------------|
| 대학회계 사업평가 성과지표 설정 보고서 | `[번호. 세세사업명]` 제목 → `< 부서, 이름(직위), ☎ >` → `□ 사업명:` → `□ 성과지표 및 목푯값`(표) → `◦ 지표 설정 근거` → `◦ 기준값 및 목푯값 설정 근거` → `◦ 달성 계획 및 전략` | 지표명에 단위: `신규 서버 이전 완료율(%)`. 산식은 근거 문장 안에: `시스템 가동율(장애일수/365일)`. `기준값은 전년도(2024년) … 결과로 설정하였고 목푯값은 매년 0.2점 상승을 목표로 설정함` |
| 대학회계 사업평가 실적보고서 | `Ⅰ 사업 개요`(`연관지표 : […]`) → `Ⅱ 추진 실적`(성과 달성 현황 표·사유표·실적 개선 노력) → `Ⅲ 예산 편성 및 집행 현황` → `Ⅳ 증빙자료` | 사유표 빈칸은 `• 해당없음`. 미집행 사유: `~절차가 필요하여 당해연도 내 집행이 어려움`. 장기발전계획 연계: `M-3-3 디지털 기반 SMART 캠퍼스 구축을 위해 …를 추진` |
| 국립대학육성사업 세부사업 실적보고서 | `필요성` → `추진목표` → `주요내용①~⑦`(`편성: 천원 / 집행: 천원 / 집행율: %`) → `추진 계획 \| 추진 실적` | `◦ (운영 성과) 사업 만족도 97%, … 4.63점(5점 만점)`, 근거는 `※`로 |
| 중기재정운용계획 사업 추진 계획서 | 표: 중점분야·세부과제(부서명)·구분(계속/신규)·세부 추진사업·투자 계획(단위: 백만원) | `< 사업명 >`, `◦ 사업기간`, `◦ 주요내용`, `◦ 향후 추진계획`, `◦ 핵심성과지표(KPI) 반영 여부` |

제출 전 점검:

- 서식 안내문을 지운다: 파란색 기울임 글자, `【작성방법】`, 가이드라인 표.
- 성과지표 금지 유형 5종을 피한다: 추상적 지표, 다른 평가지표와 중복, 단순 투입, 법적 의무, 현저히 낮은 목푯값. 2025학년도 제출본의 `본부 부서 협조비율`은 서식의 금지 예시와 같았다.
- 서식 잔재를 찾는다: 다른 부서 예시 행, `현ㅈ` 같은 입력 잔재, 두 번 들어간 사업명.
- 표 합계와 세부 내역 합계, 기간의 시작·끝 순서를 대조한다.
