# 과업심의 검토 체크리스트 (축 0 + 5축)

각 항목은 **원문 인용으로 확인 가능한 것만** 지적한다.
`(개발)` 표시는 SW 개발사업 전용 — 물품구매·구독·임차 건에서는 건너뛴다.
조문 근거와 인용문은 `references/legal-basis.md`에 있다.

---

## 축 0. 심의 성립 요건 — **내용 검토 전에 먼저 본다**

절차 하자는 내용 지적보다 상위다. 여기서 걸리면 판정 자체를 보류하고 사용자에게 알린다.

| # | 확인 | 근거 |
|---|------|------|
| 0-1 | **간소화 심의 대상인가** — ① 총 사업금액 1억원 이하 ② 상용SW·표준화 보급 정보시스템 구매 ③ 기심의 사업의 변경 없는 추가 | 대학 운영지침 §5③ |
| 0-2 | 간소화 대상이면 위원 **2인 이상 + 외부위원 과반수 이상** 지명이 있었는가 | 대학 운영지침 §5③ |
| 0-3 | 정식 심의면 **위원장 포함 5~10명 + 외부위원 과반수**를 충족하는가 | 시행령 §45①②, 대학 운영지침 §3① |
| 0-4 | 재적 과반수 출석 + 출석 과반수 찬성 요건을 갖추는가 (서면·온라인 결의 포함) | 시행령 §46②, 대학 운영지침 §6②③ |
| 0-5 | **제척 사유가 있는 위원이 참여**하지 않는가 — 특히 발주부서 결재권자가 당연직 위원장인 경우 | 대학 운영지침 §7①(2호 소속 기관·단체와 직접 이해관계), 시행령 §46③ |
| 0-6 | 위원장 제척 시 나머지 위원 중 **재호선**이 이루어졌는가. 2인 체제라면 심의 성립 불가 | 대학 운영지침 §6④ |
| 0-7 | 심의 대상이 위원회 소관인가 — 과업 내용(**적정 사업기간 산정 포함**) / 변경 / 계약금액·기간 조정 | 법 §50①, 대학 운영지침 §4 |
| 0-8 | 발주부서가 위원회에 **출석하여 설명**하였는가 (서면심의면 그 사유) | 대학 운영지침 §8 |

> **1억원 초과 사업을 2인 체제로 심의하는 것**이 실무에서 가장 흔한 하자다.
> 회차 위원 구성부터 확인하고 시작한다.

## 축 1. 금액·대가산정

| # | 확인 | 흔한 결함 |
|---|------|----------|
| 1-1 | 사업금액이 심의요청서·산출내역서·제안요청서·기본계획에서 **동일한가** | 조정 이력이 일부 문서에만 반영 |
| 1-2 | VAT 포함/제외가 **항목마다 명시**되어 있는가 | 합계에만 "(부가세 포함)", 항목은 불명 |
| 1-3 | 항목별로 **단가 × 수량 = 금액** 형식인가 | 총액만 제시 |
| 1-4 | **직접경비 세부내역**이 있는가 | 통째로 누락 |
| 1-5 | 추정가격 = 사업금액 ÷ 1.1 이 맞는가 | 반올림 오차·기재 누락 |
| 1-6 `(개발)` | 기능점수 또는 투입공수 **산정서가 존재**하는가 | 시장 견적만으로 편성 |
| 1-7 `(개발)` | 역산 FP가 과업 규모와 정합하는가 (`cost_check.py fp`) | 현저한 과소산정 |
| 1-8 `(개발)` | 유지관리·운영비가 요율제/투입공수 어느 쪽으로도 설명되는가 | 양방향 모두 불성립 |
| 1-9 | 산출근거가 **시장 견적뿐**이면 회신 업체 수·전제범위·참가자격을 확인했는가 | 1개 업체 견적이 예정가격 확정 |
| 1-10 | 계약 **총가치**에 계상되지 않은 부분이 있는가 (사업자 부담분·수익배분·초과사용 실비) | 추정가격 산정범위 왜곡 |

> 1-10이 걸리면 **중소기업자 제한경쟁·대기업 참여제한·직접구매·제안서 보상·수행실적 평가 가부**가
> 모두 흔들린다. 단독 지적이 아니라 연쇄 영향으로 쓴다.

## 축 2. 사업기간 `(개발)`

`scripts/cost_check.py period` 로 정량 대조한다.

| # | 확인 | 근거 / 흔한 결함 |
|---|------|-----------------|
| 2-0 | **별표 1 대상사업인가** — 컨설팅·운영유지관리·**상용SW 도입(커스터마이징 포함)** 은 제외 | 별표 1. 1)  ← "커스터마이징 전제"를 기간 단축 근거로 쓰면서 산정서를 낸 경우, 대상 여부부터 정리 |
| 2-1 | **적정 개발기간**과 **전체 계약기간**이 분리 표기되었는가 | 전체 계약기간을 개발기간처럼 서술 |
| 2-2 | 산정표에 **①FP 기반 적정 개발기간 산정표**가 실제로 있는가 | 법 §45①, 지침 §10①, 별표 1. 서술형 의견 5개 항목만 있으면 별표 1 미준수 |
| 2-3 | 본문이 언급한 근거자료가 **실제로 첨부**되었는가 | "12주 WBS로 산정" ← WBS 없음 |
| 2-4 | **유사사업 자료가 g2b.go.kr·spir.kr 조사자료**인가 | 별표 1. 3)③ ← 업체가 제출한 자사 실적 목록은 해당하지 않음. 업종·과업 성격 유사성도 확인 |
| 2-5 | **사업금액 1억원 초과면 산정 주체가 과업심의위원회**인가 | 지침 §10②③ ← 발주부서 "검토안"만 제출은 미흡 |
| 2-6 | 제안요청서에 **"적정 사업기간 산정 기준에 따른 사업"임을 명시**했는가 | 지침 §10④ 전단 |
| 2-7 | 제안요청서에 첨부한 **종합 산정서(별지 제4호)에서 위원명·서명이 제외**되었는가 | 지침 §10④ 단서 ← 서명란이 살아 있으면 위반 |
| 2-8 | 전문가 자문·시장 회신이 기간을 **부정**하지 않는가 | "현실성 낮다" 의견 미반영 |
| 2-9 | **적정 사업기간이 1년 초과면 장기계속계약**을 체결하는가, 그리고 **각 회계연도 예산 범위**로 이행하는가 | 법 §45② ← 기준은 전체 계약기간이 아니라 **적정 사업기간**. 장기계속이면 차수 구분·차수별 계약금액·연도별 배분 확인 |
| 2-10 | 사업종료가 다음 회계연도에 속하면 이월 근거가 있는가 | 법 §45③ |

**정량 대조 예시**

```bash
# 제시 기간·인력으로 소화 가능한 규모 상한
python3 .claude/skills/gwaeop-simui/scripts/cost_check.py period --months 3 --headcount 3   # → 약 171 FP 이하
```
이 상한을 요구사항 건수·역산 FP와 나란히 놓으면 기간 산정의 성립 여부가 드러난다.

| # | 확인 | 근거 |
|---|------|------|

## 축 5. 실현가능성·문서 정합성

| # | 확인 |
|---|------|
| 5-1 | 심의요청서 **첨부목록 ↔ 폴더 실물 파일**이 일치하는가 |
| 5-2 | 문서 내부 머리글·별첨 번호가 파일명과 일치하는가 |
| 5-3 | 법령·부처 **명칭 표기**가 현행인가 |
| 5-4 | 같은 사항을 두 곳에서 **다르게 규정**하지 않는가 (기간 기산점·이수기준·제품명·라이선스 채널) |
| 5-5 | 전문가 자문·TF 의견 중 **미해결로 남은 항목**을 "확정"으로 서술하지 않는가 |
| 5-6 | 시장 회신이 **"곤란"으로 답한 기능**이 필수 과업에 들어가 있는가 (비용 미반영) |
| 5-7 | 사업자 **자기부담 과업**이 있으면 회수 전제(수요·단가·기간)가 성립하는가 |
| 5-8 | 요구사항이 **개별 단위로** 적용단계·완료기준·검수방법을 갖는가 (그룹 단위 표만 있으면 미흡) |
| 5-9 | **SLA에 목표값과 미달 시 감액 기준**이 함께 있는가 |
| 5-10 | 기준 사용량 초과분이 "실비 별도 협의"로 열려 있는가 (계약 후 증액 통로) |
| 5-11 | 종료·인수인계(데이터 무상 이관·기술문서·SW임치·병행운영)가 규정되었는가 |
| 5-12 | **심의요청 결재권자와 심의위원장이 동일인**인가 → 제척·회피 사안, 즉시 보고 |
| 5-13 | **문서 표기 검수** — 기관·제도명 오타, 금액의 모호어(`정도`·`내외`), 부가세 포함 여부 미표기, 공문 `끝.` 마침표, 항목 번호 누락, 첨부 명칭 3자 불일치, 단위 선언 위반 → 유형·확인방법은 `output-format.md` §4 |

> 5-13은 **제조사 작성본(규격서 등)과 발주부서 작성본을 구분**한다.
> 제조사 오기는 발주부서가 고칠 수 없으므로 지적 본문이 아니라 참고 문단으로 분리한다.
