# 반복 지적 목록 (재발 탐지용)

이미 한 번 지적받은 항목이 다시 들어오는 일이 잦다.
**재발은 가장 방어하기 쉬운 지적**이므로 검토 초반에 이 표부터 훑는다.
새 지적이 확정될 때마다 여기에 delta append 한다 — 출처와 날짜를 반드시 남긴다.

## A. 조달청 구매업무 협의 지적 (2026-07, 통합홈페이지 고도화)

출처: `10_Areas/홈페이지/202607_홈페이지 구매업무 협의 검토/구매업무 협의안(정보시스템개발서비스).hwpx`

| # | 지적 원문 요지 | 탐지 키워드 | 회신한 조치 |
|---|---------------|------------|------------|
| A-1 | 정확한 사업기간 산정을 위해 "(약 N개월)" 삭제 | `약 N개월` | `계약일로부터 180일 이내`로 수정 |
| A-2 | 착수계(사업수행계획서·서약서 등) 제출기한을 계약체결 후 **10일 이내**로 | `14일 이내`, `착수계` | 10일로 수정 |
| A-3 | 자본금·매출액 등 경영상태 정보는 신용평가등급으로 확인 가능 → **삭제** | `자본금`, `부문별 매출액` | 삭제, 신용등급만 제시 |
| A-4 | **고시금액 미만 소규모 사업은 수행실적 평가 미실시가 원칙** | `수행실적`, `준공실적`, `수행실적 총괄표` | 실적 평가항목 삭제 후 배점 재배분 |
| A-5 | 제안요청서에서 **추가제안을 직·간접 요청·평가 금지** | `추가 제안`, `추가제안` | 요구사항 대응표 해당 항목 삭제 |
| A-6 | 추정가격 1억 이상 고시금액 미만 → **중소기업자간 경쟁 참가자격 추가** | `입찰참가자격`, `중소기업확인서` | 조항 신설 |
| A-7 | 부처명칭 **"기획재정부" → "재정경제부"** | `기획재정부 계약예규` | 표기 수정 |
| A-8 | 차등점수제 적용 여부가 **조달요청서와 상이** → 재검토 | `차등점수` | 미적용으로 통일 |
| A-9 | 총 배점한도 **밖의 가점 금지** | `가산점`, `배점 한도 이외` | 문구 삭제 |
| A-10 | 경영상태 주석의 **"국가종합전자조달시스템 조회"** 삭제 (이용 불가) | `국가종합전자조달시스템` | 삭제 |
| A-11 | 기술지원확약서 제출시기를 **계약체결 후 10일 이내**로 명시 | `기술지원확약서` | 명시 |
| A-12 | 기술지원협약서 품목·금액을 **산출내역서에 일치**하도록 반영 | `기술지원협약서` | 산출내역서에 표시 |
| A-13 | FP 방식 사업이면 **투입인력 예외 문구 삭제** | `투입 공수 방식`, `투입인력 요구 및 관리 금지 대상 사업이 아님` | 전체 삭제 |
| A-14 | 산출내역서는 **부가세 포함 금액**으로 작성 + **직접경비 세부 산출내역** 회신 | `산출내역서`, `직접경비` | 부가세 포함으로 재작성 |

### 실측 재발 사례

| 회차 | 재발 항목 | 비고 |
|------|----------|------|
| 2026 제8회 (원격교육연수원 시스템, 2026-08) | **A-4 · A-7 · A-10 · A-14** | 홈페이지 건 지적 후 약 1개월 만에 동일 문구 재등장 |
| DNS 시스템 도입 (정보전산원-1749, 2026-07) | **B-1 · B-2 · B-3 · B-11** | 제7차 2026-028·029와 **같은 사업계획서**(정보전산원-1688)에서 갈라진 항목 — 견적 근거 부재·금액 불일치·특정 브랜드 규격·발주기관장 = 당연직 위원 구조가 그대로 반복됨 |

## 사용법

1. 축별 검토 중 위 **탐지 키워드**를 추출 텍스트에서 grep 한다.
2. 걸리면 원문 인용 + 이전 지적 출처(A-N / B-N)를 함께 적고 **재발** 표시를 단다.
3. 새로 확정된 지적은 표 하단에 append 하고 출처·회차를 남긴다.
   추측이나 미확인 사항은 넣지 않는다 — 이 표는 확인된 선례만 담는다.
