# 5개 축 대조 (deliverable-review Step 2 상세)

## A. 과업 미이행·미입증 — 검수 보류 사유

과업지시서의 각 요구 항목을 산출물 전문 검색으로 확인한다. 판정은 셋 중 하나다:
**이행 확인 / 서술 없음 / 서술은 있으나 근거 없음**. "서술 없음"이 가장 강한 지적이다 —
반박하려면 수행사가 자료를 내야 하기 때문이다.

필수 산출물 목록과 실제 제출 목록을 대조해 **누락 문서**를 먼저 잡는다. 수행계획서의 산출물
목록 자체에서 빠져 있다면 그건 누락이 아니라 **과업 축소**이므로 별도로 짚는다.

## B. 문서 간 모순·기재 오류

같은 사실을 두 문서가 다르게 적은 것. 근거는 불일치 자체이므로 **어느 쪽이 맞는지 단정하지 말고
어느 쪽으로 통일할지 회신을 요구**한다. 자주 나오는 축: 사업(계약)건명 · 사업기간 · 이슈 유무 ·
대가 산정 방식 · 현행 환경 사양 · 시험 항목 번호.

## C. 금액·기간 정합

총액과 공급가+부가세가 맞는지, 완수기한 대비 완료보고일이 지체인지(지체면 지체상금율로 금액 계산),
대가 산정 방식이 산출내역서와 완료보고서에서 같은지 확인한다.

## D. 이상 없음 — **반드시 적는다**

확인했고 문제가 없는 항목을 노트에 명시한다(금액 일치, 하자보수 조건 부합, 지체 없음 등).
안 적으면 다음 회차에 같은 항목을 다시 검토하게 되고, 수행사에게도 무엇이 통과인지 전달되지 않는다.

## E. 문서로 증명 불가 → 실물 확인 목록

"플러그인 없이 브라우저에서 조회", "SSO 로그인", "관리자 화면", "배치 동작"처럼 화면을 켜야 아는
항목은 지적이 아니라 **검수 전 확인 체크리스트**로 뽑는다. 이걸 지적으로 쓰면 수행사는 문서를
고쳐서 회신하고, 정작 동작은 확인되지 않은 채 검수로 넘어간다.
