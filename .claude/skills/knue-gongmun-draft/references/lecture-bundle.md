# C 유형 — 특강 결과 보고 · 상시학습 인정 요청

정보전산원이 직원 대상 특강을 연 뒤 보내는 공문 두 건과 붙임 묶음이다. 기수마다 같은 구성을
반복하므로 **직전 기수 폴더를 선례로 복제**하고, 양식을 사용자에게 다시 달라고 하지 않는다.
1기(2026-10-01·02)와 2기(2026-10-27·30)가 모두 이 구성으로 결재·상신됐다.

## 선례 위치

| 무엇 | 경로 |
|------|------|
| 근거 노트(특강 실시·참석자·결과 보고·공문번호) | `12_Projects/2026/생성형 인공지능 플랫폼 도입/직원 특강/생성형-ai-플랫폼-직원-특강-2026-09.md` |
| 허브 노트(발송 기록 대상) | `12_Projects/2026/생성형 인공지능 플랫폼 도입/_생성형 인공지능 플랫폼 도입.md` |
| 기수 폴더 | `12_Projects/2026/생성형 인공지능 플랫폼 도입/직원 특강/{N}기/` |
| 결과 보고 hwpx 골격 | `knue-report-draft` → `references/knue-house-style.md` 「특강·행사 결과 보고」 |

다른 사업의 특강이어도 같은 구성을 쓴다. 그 사업 폴더에 기수 폴더가 없으면 위 2기 폴더를 선례로 삼는다.

## C-1. 특강 결과 보고 (내부결재)

- 형식: 내부결재(정보화지원팀장 → 정보보안담당관 → 정보전산원장).
- 관련: 그 기수의 「… 관련 특강 실시」 내부결재 공문(근거 노트에 번호가 있다).
- 붙임은 기수 폴더 바로 아래에 둔다.
  1. `붙임1. 「{특강명}」 특강 결과 보고.hwpx` — 직전 기수 hwpx를 복제해 수치만 바꾼다. 작성은 `knue-report-draft`·`prod:hwpx`.
  2. `붙임2. 출석부.pdf` — 서명부 스캔본.
  3. `붙임3. 강의자료.pdf`
- 입력: 만족도 설문 응답 CSV(기수 폴더에 보관), 서명부 스캔, 강의자료 PDF, 메일 수신 명단.
  참석자 명단의 이름·소속·직급은 메일 수신 명단, 고유번호는 출석부 판독으로 채운다.
  판독이 불확실한 번호는 추정하지 말고 사용자에게 확인한다.

## C-2. 상시학습 인정 요청 (총무과)

- 수신: 한국교원대학교총장(총무과장). 상신 공문이라 **번호는 결재가 나야 생긴다** — Step 6 기록 때 번호를 비워 두고 받으면 덧붙인다.
- 붙임은 `{N}기/상시학습 인정 요청/` 폴더에 다음 이름·순서로 모은다.

| 붙임 | 파일명 | 만드는 법 |
|------|--------|-----------|
| 1 | `붙임1. 상시학습 인정 요청 명단.xlsx` | 직전 기수 xlsx를 복제해 서식 유지. 1행 제목, 2행 `{일시}, {장소}`, 3행 `순번·소속·고유번호·성명`. **참석자 전원(조교 포함)**을 넣는다 — 1기·2기 모두 29명 전원으로 상신했고 사용자가 확인함(2026-10-30). 고유번호는 결재된 결과 보고 hwpx의 참석자 명단에서 가져온다 |
| 2 | `붙임2. 「{사업명}」 관련 특강 실시.pdf` | 특강 실시 공문 PDF. 볼트에 없으면 사용자에게 넣어 달라고 한다(유일하게 만들 수 없는 파일) |
| 3 | `붙임3. 「{특강명}」 특강 결과 보고.pdf` | 결재 완료된 결과 보고 공문 PDF |
| 4 | `붙임4. 출석부.pdf` | C-1 붙임2 사본 |
| 5 | `붙임5. 관련 사진.zip` | 결과 보고 hwpx 마지막 장의 사진을 jpg로 꺼내 압축. 해상도가 낮으면 원본 사진이 있는지 묻는다 |

## 확인할 것

- **장소 표기.** 결재 공문과 붙임(결과 보고·출석부)의 장소가 다를 수 있다. 2기는 결재 공문 201호,
  붙임 202호였고 실제는 201호였다. 다르면 사용자에게 확인하고, 이미 결재된 문서는 고치지 않는다.
- 공문번호·일시·인원은 근거 노트와 결재 공문 원문에서만 가져온다. 없으면 비워 두고 묻는다.
