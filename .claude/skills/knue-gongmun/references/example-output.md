# 공문 본문 예시

## 예시 1: 관련 공문 있는 경우 (현장실습 기능 개선)

```
제목: 통합학사시스템 기능 개선 결과 안내(현장실습 관련)

1. 관련: 교학처-1234(2026. 5. 12.) "통합학사시스템 현장실습 기능 개선 요청"

2. 위와 관련하여, 통합학사시스템을 다음과 같이 개선하였음을 알려드립니다.

  가. 현장실습 > 현장실습 신청 > 신청 현황
    - 학생 신청 현황 목록에 지도교수명 컬럼 추가

  나. 현장실습 > 담당자 관리 > 승인 처리
    - 일괄 승인 처리 시 미승인 항목 필터 기능 추가

3. 개선일: 2026년 5월 20일.  끝.
```

## 예시 2: 관련 공문 없는 경우 (자체 개선 — 수강신청 포함)

```
제목: 통합학사시스템 기능 개선 결과 안내(수강신청 관련)

2. 통합학사시스템 및 수강신청시스템을 다음과 같이 개선하였음을 알려드립니다.

  가. 수강신청 > 수강신청 관리 > 수강신청 현황
    - 수강신청 인원 초과 시 대기 신청 허용 기능 추가

  ※ 권한 설정은 각 학과 담당자가 별도 요청 시 부여 예정

3. 개선일: 2026년 6월 10일.  끝.
```

---

## 형식 메모

- `{부서명}-{문서번호}({YYYY. M. D.})` 형식: 예) `교학처-1234(2026. 5. 12.)`, `학사관리과-567(2026. 3. 4.)` — 날짜 없이 번호만 쓰지 말 것 (부서가 매년 번호를 초기화하므로 날짜 없인 다른 해 동일번호 문서와 구분 불가)
- 날짜 변환: `2026-05-12` → `2026. 5. 12.` (월·일 앞 0 제거, 점 뒤 공백)
- 수신처 2개 이상: 본문 동일, 기안 시 수신처 각각 별도 입력
