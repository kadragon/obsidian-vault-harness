# 주간업무회의 자료 생성

팀 전체의 주간업무회의 제출 자료를 정리한다.
본인 담당 업무는 볼트에서 자동 수집하고, 팀원 항목은 사용자가 제공한다.

---

## 1단계: 기간 설정

**기본값은 1주** (별도 지정이 없으면 1주로 진행):

- **1주**: 오늘이 속한 주의 월요일 ~ 일요일 (이번 주 실행 중인 업무 중심)
- **2주**: 오늘이 속한 주의 월요일 ~ 다음 주 일요일 (예정 업무·마감 포함)

오늘 날짜에서 기간 범위를 계산한다. (예: 오늘 2026-05-02(토) → 1주: 04-27~05-03, 2주: 04-27~05-10)

---

## 2단계: 볼트에서 본인 업무 수집

아래 세 경로에서 활성 노트를 찾는다. 디렉토리가 없으면 해당 경로를 건너뛰고 사용자에게 알린다.

```bash
bash .claude/skills/weekly-report/scripts/collect_active_notes.sh .
```

각 노트에서 Read로 추출:
- **프로젝트명**: 폴더명 우선 (`12_Projects/2026/계절학기 현장실습 운영/` → `계절학기 현장실습 운영`); 폴더명이 식별하기 어려운 경우(영문 코드, 숫자만 등)에 한해 `type: project` 노트의 `# 제목` 사용
- **현황**: `## 현황` 섹션 불릿
- **할 일**: `## 할 일` 섹션의 **미완료 항목(`- [ ]`)만** + 마감일(`📅 YYYY-MM-DD`)
- **담당 부서**: `#부서/학사관리과/...` 태그 → `[학사관리과]` 형식

> **완료 노트 제외**: `## 할 일`의 모든 항목이 `- [x]`(완료)이거나 미완료 항목이 하나도 없으면, 해당 노트는 보고서에 포함하지 않는다. `status: open` 이더라도 남은 할 일이 없으면 이번 주 보고 대상이 아니다.

**기간 필터링** — 다음 중 하나면 포함:

| 조건 | 설명 |
|------|------|
| 마감일이 기간 내 | `📅 YYYY-MM-DD`가 보고 기간 안 |
| 마감일 없는 진행 중 업무 | `status: active` 또는 진행 중인 개발 등 |
| 기간 내 날짜가 명시된 이벤트 | `## 현황`에 보고 기간 내 날짜 포함 |

마감이 기간보다 훨씬 이후이고 이번 주 진행사항이 없는 노트는 제외.

---

## 3단계: 팀원 항목 수집

볼트 수집 후 **사용자에게 묻는다**:

> "볼트에서 수집한 담당 업무 목록입니다. 팀원 항목이나 추가할 내용이 있으면 붙여 넣어 주세요. 없으면 이대로 진행합니다."

사용자가 내용을 제공하면 볼트 항목과 합쳐서 전체를 형식화한다.
"없음" 또는 응답이 없으면 볼트 항목만으로 진행한다.

---

## 4단계: 형식 적용

### 기본 구조

```
프로젝트명/업무명 (날짜범위 또는 수치)
- [담당부서] 세부 내용 (~마감일)
- 세부 내용 2
단독 업무·마감: ~M. D.
단독 완료·결과 항목 (결과 요약)
```

- 하위 항목이 있으면 프로젝트명 아래에 `-` 로 나열
- 하위 항목이 없거나 단독 성격이면 독립 한 줄로 처리

### 형식 규칙

| 항목 | 규칙 | 예시 |
|------|------|------|
| 날짜 | M. D. (앞 0 제거) | `4. 21.`, `5. 8.` |
| 날짜 범위 | `M. D.~M. D.` 또는 `M. D.~D.` | `4. 21.~30.` |
| 마감 — 불릿 내 | `~M. D.` 또는 `: ~M. D.` | `단일로그인 화면 검토: ~4. 29.` |
| 마감 — 독립 행 | `업무명(~M. D.)` (괄호) | `불용물품 목록 제출(~4. 17.(금))` |
| 마감에 추가 정보 | 괄호 안에 콤마로 | `만족도 조사(13개 항목, ~4. 30.(목))` |
| 요일 포함 | 날짜 뒤 괄호 — 알 때는 반드시 포함 | `~4. 16.(목)`, `5. 8.(금) 13시` |
| YYYY-MM-DD 변환 | `2026-04-30` → `4. 30.` (요일 계산 후 추가) | — |
| 진행 중 항목 | 끝에 `(계속)` | `현장실습 운영(계속)` |
| 담당 부서 | `[부서명]` 내용 앞에 | `[학사관리과] 학점교류 ...` |
| 관련 항목 묶기 | `/` 로 연결 | `계절학기 운영 / 교육실습 시수 인정 협의` |
| 수치·진척도 | 괄호 안에 | `92.35% 달성`, `앱설치: 1,392건(11.7%↗)` |

### 항목 정렬 순서

1. 마감 임박 항목 (기간 내 마감, 빠른 순)
2. 진행 중 주요 프로젝트 (`(계속)` 항목)
3. 예정 행사·회의
4. 기간 이후지만 진척 공유가 필요한 항목

---

## 5단계: 출력 및 확인

초안을 **코드 블록 없이** 바로 출력한다 (복사하기 편하게).

출력 후: "추가하거나 수정할 내용이 있으면 말씀해 주세요."

사용자 피드백이 있으면 수정 후 전체를 다시 출력한다.

---
