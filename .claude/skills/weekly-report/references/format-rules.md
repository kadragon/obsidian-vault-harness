# 형식 규칙 (weekly-report 4단계 상세)

## 기본 구조

```
프로젝트명/업무명 (날짜범위 또는 수치)
- [담당부서] 세부 내용 (~마감일)
- 세부 내용 2
단독 업무·마감: ~M. D.
단독 완료·결과 항목 (결과 요약)
```

- 하위 항목이 있으면 프로젝트명 아래에 `-` 로 나열
- 하위 항목이 없거나 단독 성격이면 독립 한 줄로 처리

## 형식 규칙

| 항목 | 규칙 | 예시 |
|------|------|------|
| 날짜 | M. D. (앞 0 제거) | `4. 21.`, `5. 8.` |
| 날짜 범위 | `M. D.~M. D.` 또는 `M. D.~D.` | `4. 21.~30.` |
| 마감 — 불릿 내 | `~M. D.` 또는 `: ~M. D.` | `단일로그인 화면 검토: ~4. 29.` |
| 마감 — 독립 행 | `업무명(~M. D.)` (괄호) | `불용물품 목록 제출(~4. 17.(금))` |
| 마감에 추가 정보 | 괄호 안에 콤마로 | `만족도 조사(13개 항목, ~4. 30.(목))` |
| 요일 포함 | 날짜 뒤 괄호 — 알 때는 반드시 포함 | `~4. 16.(목)`, `5. 8.(금) 13시` |
| YYYY-MM-DD 변환 | `2026-04-30` → `4. 30.` (요일 계산 후 추가) | — |
| 진행 중 항목 | 끝에 `(계속)` | `현장실습 운영(계속)` |
| 담당 부서 | `[부서명]` 내용 앞에 | `[학사관리과] 학점교류 ...` |
| 관련 항목 묶기 | `/` 로 연결 | `계절학기 운영 / 교육실습 시수 인정 협의` |
| 수치·진척도 | 괄호 안에 | `92.35% 달성`, `앱설치: 1,392건(11.7%↗)` |

## 항목 정렬 순서

1. 마감 임박 항목 (기간 내 마감, 빠른 순)
2. 진행 중 주요 프로젝트 (`(계속)` 항목)
3. 예정 행사·회의
4. 기간 이후지만 진척 공유가 필요한 항목
