# 주간업무회의 자료 생성

팀 전체의 주간업무회의 제출 자료를 정리한다.
본인 담당 업무는 볼트에서 자동 수집하고, 팀원 항목은 사용자가 제공한다.

---

## 1단계: 기간 설정

**기본값은 1주** (별도 지정이 없으면 1주로 진행):

- **1주**: 오늘이 속한 주의 월요일 ~ 일요일 (이번 주 실행 중인 업무 중심)
- **2주**: 오늘이 속한 주의 월요일 ~ 다음 주 일요일 (예정 업무·마감 포함)

기간·요일은 아래 수집기가 계산한다. `--date`를 생략하면 오늘, 과거·미래 보고면 기준일을 명시한다.

---

## 2단계: 볼트에서 본인 업무 수집

아래 세 경로에서 활성 노트를 찾는다. 디렉토리가 없으면 해당 경로를 건너뛰고 사용자에게 알린다.

```bash
bash .claude/skills/weekly-report-compile/scripts/collect_active_notes.sh . --json --weeks 1
# 특정 기준일의 2주 보고
bash .claude/skills/weekly-report-compile/scripts/collect_active_notes.sh . --json --weeks 2 --date 2026-11-01
```

활성 여부는 `.md`의 맨 앞 frontmatter로 판정한다. 대상 없음은 exit 0, 누락 폴더는 stderr 경고 후 건너뛰며, 읽기 실패는 exit 1이다. exit 1이면 부분 목록으로 보고서를 만들지 않고 실패 경로를 확인한다. `--json` 생략 시 기존 영역별 경로 목록만 출력한다.

JSON의 `period.start/end`에서 ISO 날짜·요일·표시 문자열을 사용한다. `notes`의 필드:
- `title`·`project_name`: 제목·프로젝트 폴더명. 폴더명이 숫자·코드 등으로 불명확할 때만 제목을 사용한다.
- `tasks`: 코드 펜스를 제외한 미완료 체크박스, `section`, `due`(날짜·요일), 원문 `raw`·`line`. 마감일 오름차순이며 날짜 없음·오류는 뒤에 온다. `할 일`·`주요 일정`·구형 `🏷 Todo`를 인식하고 다른 섹션은 검토 대상으로 표시한다.
- `context`: 현황·수정 사유·발생 정보의 원문과 줄번호, 명시된 연월일(`YYYY-MM-DD` 또는 `YYYY. M. D.`), 기간 내 이벤트 여부. 연도 없는 날짜는 추정하지 않는다.
- `departments`: `#부서/`에서 추출한 부서명·원문·줄번호. `[부서명]`으로 출력한다.
- `candidate_reasons`·`review_required`: 포함 후보 근거와 확인할 항목. 기간 내 마감·현황 이벤트, 기한 경과, 기간 이후, 날짜 없음·오류, 할 일 섹션 밖, 미완료 항목 없음 등을 구분한다.

추출값은 분류 보조 자료이며 보고서 포함 여부의 확정값이 아니다. `review_required`를 보고 원문 해당 줄 주변만 추가로 읽어 판단한다. 실제로 남은 업무가 없는 노트는 보고서에서 제외한다.

**기간 필터링** — 다음 중 하나면 포함:

| 조건 | 설명 |
|------|------|
| 마감일이 기간 내 | `📅 YYYY-MM-DD`가 보고 기간 안 |
| 마감일 없는 진행 중 업무 | `status: active` 또는 진행 중인 개발 등 |
| 기간 내 날짜가 명시된 이벤트 | `## 현황`에 보고 기간 내 날짜 포함 |

기간 밖·날짜 없는 항목은 수집기가 버리지 않는다. 이번 주 진행사항·현황과 대조한 뒤 포함 여부를 판단한다. 마감이 훨씬 이후이고 이번 주 진행사항이 없다는 근거가 있을 때만 보고서에서 제외한다. 잘못된 날짜·연도 없는 날짜는 원문이나 사용자 정보로 확인하며 임의 보정하지 않는다.

---

## 3단계: 팀원 항목 수집

볼트 수집 후 **사용자에게 묻는다**:

> "볼트에서 수집한 담당 업무 목록입니다. 팀원 항목이나 추가할 내용이 있으면 붙여 넣어 주세요. 없으면 이대로 진행합니다."

사용자가 내용을 제공하면 볼트 항목과 합쳐서 전체를 형식화한다.
"없음" 또는 응답이 없으면 볼트 항목만으로 진행한다.

---

## 4단계: 형식 적용

상세는 `references/format-rules.md`를 따른다 (기본 구조·형식 규칙표·항목 정렬 순서).

---

## 5단계: 출력 및 확인

초안을 **코드 블록 없이** 바로 출력한다 (복사하기 편하게).

출력 후: "추가하거나 수정할 내용이 있으면 말씀해 주세요."

사용자 피드백이 있으면 수정 후 전체를 다시 출력한다.
