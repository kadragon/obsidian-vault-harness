## 현황

```dataviewjs
const order = ["대기", "진행", "반영대기", "보류", "수용", "완료"];
const rows = dv.current().file.lists.where(l => l["상태"]);
const n = s => rows.where(l => String(l["상태"]).trim() === s).length;
dv.paragraph(order.map(s => `${s} **${n(s)}**`).join(" · ") + ` (테마 ${rows.length}개)`);
```

## 테마

상태 값: `대기`(미착수) · `진행`(일부 조치) · `반영대기`(코드 완료, 운영 반영·확인 남음) · `보류`(사유·재개 조건 명시) · `수용`(위험 수용 종결) · `완료`(운영 확인까지 끝남)

`건수`는 테마에 배정된 리드 총수다. 테마 ID는 문자(A~Z) 또는 T{번호} 중 한 체계만 쓴다. 완료 테마는 "남은 것 없음", 조치 노트가 없으면 기록 노트를 링크한다.

- **A** {주제} — [상태:: 대기] — [건수:: 0] — {남은 것 한 줄} — [[대표 조치 노트]]
